## Respuesta a inicidentes
- Se centra en la respuesta rápida y efectiva a los incidentes de seguridad una vez que se han producido.
- Esto implica identificar, contener, mitigar y recuperarse de los incidentes de seguridad de manera opirtuna.

Preparación -> Detección y análisis -> Contención, Erradicación y Recuperación -> Acciones Post incidente
## Análisis forense
- Requiere experiencia
## Actualización de políticas y procedimientos
- Después de un inciente de seguridad, se revisan y actualizan las políticas y procedimientos de seguridad para abordar las vulnerabilidades identificadas y prevenir futuros incidentes similares.
## Mejora continua
- La seguridad reactiva a menudo conduce a mejoras en la seguridad de una organización a través de la identificación de áreas problemáticas y la implementación de medidas correctivas
## Pasos
1. Identificar
2. Revisar
3. Evaluar
4. Mitigar
5. Prevenir
### 3. Evaluación de impacto (Evaluar)
- Después de un inicidente de seguridad, se realiza una evaluación del impacto para determinar el alcande del daño y las medidas necesarias para mitigar los riesgos asociados
#### Colaboración con autoridades y terceros
- En casos graves, la seguridad reactiva puede implicar la colaboración con las autoridades legales y terceros, como proveedores de servicios de seguridad gestionados (MSSP), para abordar el incidente y minimizar el impacto 
# Seguridad proactiva
- Aquí hay que detectar y corregir las vulnerabilidades del sistema antes de que el ciberataque se concrete.
- Hay que prepararse antes del ataque
## Estrategias
### Implementaciones de controles de seguridad
- Establecer controles adecuados como firewalls, sistemas de detección de intrusiones (IDS), sistemas de preención de intrusiones (IPS), antivirus de phishing y la gestión segura de datos
### Cifrado de datos
Utilizar cifrado para proteger datos sensibles en tránsito y en reposo, reduciendo así el riesgo de exposición en caso de violación de seguridad.
