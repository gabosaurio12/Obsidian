## Codificación segura
- Minimizan vulnerabiildades
- No codificar seguro es como construir una casa sin considerar robos o riesgos
- Ejemplos:
	- Validación de entradas
	- Autenticación
	- Comunicación
		- Los datos que viajan están encriptados (como en https)
	- Almacenamiento
		- Almacenar información confidencialmente
	- Administración de parches
		- Actualizaciones para mejorar la seguridad
	- Pruebas de seguridad
		- Probar la penetración
		- Probar inyección
		- El código debe ser robusto y resiliente
	- Colaboración
		- Promover una conciencia de seguridad
