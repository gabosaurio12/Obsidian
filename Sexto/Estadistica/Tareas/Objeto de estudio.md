## Variables

| Variable                   | Descripción                                                                                       | Tipo de variable                 | Valores                                                                                                                             |
| :------------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Tipo de guitarra           | Indica cómo está construida la guitarra y qué características puede llegar a tener                | Cualitativa, Nominal             | { Clásica, Acústica, Eléctrica, Electroacústica, Flamenca, De 12 Cuerdas }                                                          |
| Tamaño                     | Indica el tamaño de una guitarra y su escala                                                      | Cualitativa, Nominal             | { 1/4, 1/2, 3/4, 7/8, 4/4 }                                                                                                         |
| Peso                       | Indica el peso en kilogramos de una guitarra                                                      | Cuantitativa, Coninua, Razón     | [0, 10] KG                                                                                                                          |
| Ancho de cuerpo            | Indica el ancho del cuerpo de la guitarra vista desde el costado en centímetros                   | Cuantitativa, Continua, de Razón | [0, 20] CM                                                                                                                          |
| Alma                       | Indica si la guitarra tiene un alma                                                               | Cualitativa, Nominal             | { Si, No }                                                                                                                          |
| Trastes                    | Indica la cantidad de trastes que tiene una guitarra                                              | Cuantitativa, Discreta, de Razón | [0, 35]                                                                                                                             |
| Material del cuerpo        | Indica la madera con la que está construido el cuerpo                                             | Cualitativa, Nominal             | { Abeto, Cedro, Palorrosa, Caoba, Arce, Sapeli }                                                                                    |
| Material del brazo         | Indica la madera con la que está construido el brazo                                              | Cualitativa, Nominal             | { Caoba, Arce }                                                                                                                     |
| Material del diapasón      | Indica la madera con la que está construido el diapasón                                           | Cualitativa, Nominal             | { Ébano, Palorrosa }                                                                                                                |
| Tipo de puente             | Indica el tipo del puente de la guitarra                                                          | Cualitativa, Nominal             | { Fijo, Semiflotantes, Flotantes }                                                                                                  |
| Tipo de clavijero          | Indica el tipo de clavijero que tiene una guitarra                                                | Cualitativa, Nominal             | { De Bloqueo, Selladas, Abiertas, De Madera }                                                                                       |
| Material de cuerdas agudas | Indica el material con el que están fabricadas las cuerdas agudas (mitad inferior) de la guitarra | Cualitativa, Nominal             | { Nylon, Fluorocarbonato, Níquel puro, Acero inoxidable }                                                                           |
| Material de cuerdas graves | Indica el material con el que están fabricadas las cuerdas graves (mitad superior) de la guitarra | Cualitativa, Nominal             | { Entorchado de Bronce con núclo de Nylon, Entorchado de Bronce, Fósforo-Bronce, Núcleo de acero con entorchado de acero niquelado} |
| Calibre de cuerdas         | Indica el grosor de las cuerdas de la guitarra                                                    | Cualitativa, Nominal             | { 0.008 - 0.038, 0.009 - 0.042, 0.010 - 0.046, 0.011 - 0.052, 0.012 - ∞ }                                                           |
| Diámetro de boca           | Indica el diámetro de la boca de la guitarra en centímetros                                       | Cuantitativa, Continua, de Razón | [0, 20] CM                                                                                                                          |
| Largo de brazo             | Indica el largo del brazo de la guitarra en centímetros                                           | Cuantitativa, Continua, de Razón | [0, 20] CM                                                                                                                          |
| Tipo de brazo              | Indica la clasificación del tipo de brazo de la guitarra                                          | Cualitativa, Nominal             | { Tipo C, Tipo C Moderno, Tipo D, Tipo U, Tipo V, Tipo C Grande}                                                                    |
