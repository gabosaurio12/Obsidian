xz## Historia de .NET
Es creado por Microsoft como una copia de Java porque no pudo ni comprarlo ni tumbarlo.
Es una plataforma, no un lenguaje, soporta varios entornos de desarrollo (gracias al runtime).
## Comandos de .NET (UNIX)
dotnet --list-sdks -> lista sdks
dotnet new --list -> Lista de proyectos que se pueden crear
dotnet new webapp -> crear una web app
dotnet run -> correr el server
dotnet publish -c release -> publica la página
sudo dotnet Calculadora2026.dll --urls=http://0.0.0.0:8080 -> cambia el puerto
## Desarrollo web
Web significa que usamos el protocolo http como mecanismo para comunicar los componentes de la aplicación del cliente y el servidor.
### Carpeta release y release/publish
Lo que hay en la carpeta publish ya viene con formato (CSS, JS, etc), se ve bonita, en la carpeta release solo se ve la app en crudo.
### Bootstrap
Es un framework para diseñar páginas web.
### Páginas Razor
La página principal de un sitio web es el index, a donde te envía cuando no buscas una página de la web específica.
