## Proyecto final
- Resolver una problemática social o empresarial mediante la implemetación de una aplicación web
- Ser un proyecto bajo la arquitectura Cliente - Servidor a 3 capas (Frontend, Middleware (API Rest) y Backend)
- Estar diseñado y programado para ser una aplicación web adaptativa (Responsive) debe de poder visualizarse tanto en pantallas normales de laptop o pc, así como en smartphones y tablets
- Propuesta libre, cada equipo de trabajo tendrá la libertad de plantear una problemática que identifique de algún sector económico o social que se pueda resolver mediante la implementación de un sistema web
### Tecnologías a usar
- Frontend: HTML, CSS, JavaScript de forma nativa o utilizar algún framework de desarrrollo web que utilice esas tecnologías como Oracle JET, Vue.js, React.js, Flutter web, etc.
- Middleware (API Rest): Java, C#, php, Python, etc. Es libre siempre y cuando se sigan los lineamientos de una API Rest, así como la implementación de buenas prácticas de seguridad como autenticación mediante token de acceso, cifrado de datos, etc.
- Backend: Solo estará conformado por la base de datos:
	- Si se opta por una BD relacional se recomienda SQL Server
	- Si se opta por una OO, se recomienda MongoDB
### Herramientas a utilizar
- Gestión de tiempo: Clockify
