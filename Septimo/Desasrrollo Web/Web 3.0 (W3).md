Apareció por primera vez en el 2006 en un artículo de Jeffrey Zeldman. Hace referencia a una web como una asociación de programas inteligentes que utilizan datos semánticos para hacer más eficientes ciertos procesos de búsqueda de información o procesamiento de datos.
Aún no hay una definición formal de lo que es o significa la web 3.0, sin embargo, dentro de sus capacidades incluyen los conceptos:
- Apps
- Smartphones
- IA
- Web semántica
- 3D
## Bases de datos

El primer paso hacia la W3 es el nacimiento de la Data Web la cual permite un nuevo nivel de integración de datos y aplicación interoperable, haciendo datos tan accesibles y enlazables como las páginas web.
El objetivo principalmente es hacer que los datos estructurados sean accesibles utilizando RDF (Resource Description Framework), el cual es un modelo de metadatos basado en XML.

También es importante añadir una capa de seguridad sobre los datos y transacciones que se manejan en la web, para ello han surgido tecnologías interesantes, la más destacada de ellas son las cadenas de bloques o **Blockchain**.
La web de datos, se considera el primer paso para lelgar a lo que se conoce como "web semántica".

## IA

W3 también ha sido utilizada para describir el camino evolutivo de la red que conduce a la IA.
Compañías como Google, Facebook, IBM, entre otras, están implementando nuevas tecnologías que cosechan información del comportamiento de las personas en la web, sus preferencias, tiempos de uso, ubicación, etc.
Con esta base de infromación han logrado crear algoritmos que permiten hacer predicciones o sugerencias de elementos que puedan gustar a ciertos sectores.
## Evolución al 3D

Otro posible camino es hacia la visión 3D, liderada por el Web 3D Consortium. Esto implica la transformación de la Web en una serie de espacios 3D.
Esto podría abrir neuvas formas de conectar y colaborar, utilizando espacios tridimensionales.
# Web 4

Propone un nuevo modelo de interacción con el usuario más completo y personalizado, que permita acceder y explorar toda la información y conocimiento generada en la W4.

Se funadmenta en cuatro pilares:
- Comprensión del lenguaje natural (NLU) y técnicas de Speech-to-Text
- Nuevos modelos de comunicación máquina-máquina (M2M). La red estarpa formada por agentes inteligentes en la nube. que serán capaces de comunicarse entre sí y delegar la respuesta al agente adecuado. Este conepto es una de las piedras angulares de IoT
- Uso de información de contexto del usuario. Sentiment analysis, geolocalización u otros sensores
- Nuevo modelo de interacción con el usuario. Para que la web no se convierta en un mero almacén de información son necesarios nuevos modelos de interacción o incluso ejecutar acciones concretas que den respuesta a las necesidades de los usuarios, haciendo hincapié en su uso sobre dispositivos móviles o incluso poder llegar al nivel de integración humano-máquina como los propuestos por Neuralink
