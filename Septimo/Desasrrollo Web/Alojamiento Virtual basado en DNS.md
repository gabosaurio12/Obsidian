Bajo este esquema de alojamiento el servidor permite alojar varios nombres de dominio asociados a la misma dirección IP.
Para lograr esto, es necesario que se cree una tabla de nombres de dominio y se genere una ruta específica donde se encontrarán los archivos o recursos de cada nombre de dominio, el cual se denominará **vhost** (virtual host).
Por úlitmo, se debe configurar en el servidor a nivel de sistema operativo la asociación entre cada DNS con la misma dirección IP.
Este esquema es uno de los más accesibles y rápidos de implementar, sin embargo, tiene como principal desventaja de que dependemos forzosamente de un DNS para poder acceder a cada sitio o sistema web alojado.

## Xampp

Es un paquete de programas de software libre, desarrollado por la comunidad de Apache Friends. Incluye variedad de utilidades como un servidor web, un servidor de base de datos, soporta los lenguajes de programación más utilizados en el ecosistema web, así como herramientas de gestión como PHPMyAdmin, Filezilla FTP Server, OpenSSL, entre otras.
Su nombre significa:
- **X**: Hace referencia a que es un paqute multiplataforma (Cross-platform)
- **A**: Hace referenica al servidor web Apache
- **M**: Inicialmente hacía referencia al gestor de base de datos MySQL, a partir de la versión 5.6.15 se cambia por el manejador MariaDB
- **P**: Hace referencia al lenguaje de programación PHP, este lenguaje es bastante conocido y uno de los más usados para sistemas web
- **P**: Hace referencia a otro lenguaje, Perl, el cual está enfocado en la administración del sistema y progamación de red
