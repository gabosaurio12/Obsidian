# 🔊 Configuración Base Limpia

Esta es la base para sonidos pop limpios (Camila / Coldplay).

## Amplificador

|Control|Valor|
|---|---|
|Gain|1–2 (lo más limpio posible)|
|Treble|7–8|
|Middle|5–6|
|Bass|3–4|

**Nota:**  
El gain del ampli suena sucio, así que mantenlo **muy bajo** y controla el volumen con el master.

---

## Boss SD-1 (modo boost limpio)

|Control|Posición|
|---|---|
|Drive|Apenas arriba del mínimo|
|Tone|Mitad|
|Level|Aproximadamente 2/3|

Esto convierte el pedal en un **boost limpio** en lugar de distorsión.

# 🎸 Selector de Pastillas

Tu guitarra tiene **3 posiciones**:

|Posición|Pastilla|Sonido|
|---|---|---|
|Arriba|Mástil|Cálido, suave|
|Centro|Ambas|Balanceado|
|Abajo|Puente|Brillante, agresivo|

### Referencia rápida

- **Sonido suave:** mástil
    
- **Sonido balanceado:** centro
    
- **Sonido brillante:** puente

# 🎵 Sonido tipo _Todo Cambió_ (Camila)

### Configuración

**Pastilla**

```
Mástil o Centro
```

**Ampli**

```
Gain: 1–2
Treble: 6–7
Middle: 5–6
Bass: 4–5
```

**SD-1**

```
Drive: mínimo
Tone: medio
Level: alto
```

### Técnica

- Arpegios suaves
    
- Rasgueos ligeros
    
- Dinámica tranquila
    
- No tocar agresivo
    

El secreto es que la guitarra **acompaña a la voz**.

# 🌌 Sonido tipo _Fix You_ (Coldplay – solo)

El sonido de Jonny Buckland es:

```
Limpio
Brillante
Atmosférico
Con delay
```

## Configuración sin delay (con tu equipo actual)

**Pastilla**

```
Puente
(o centro si suena muy chillón)
```

**Ampli**

```
Gain: 2
Treble: 7–8
Middle: 5–6
Bass: 3–4
```

**SD-1**

```
Drive: mínimo
Tone: medio
Level: alto
```

## Técnica

- Tocar suave
    
- Dejar sonar las notas
    
- Usar vibrato leve
    
- No atacar fuerte

# ⚠️ Lo que falta para sonar igual

El sonido real del solo tiene:

```
Delay
Reverb
```

Sin eso sonará **más seco**, pero la base seguirá funcionando.

### Pedales baratos recomendados (futuro)

- Behringer DD400
    
- NUX Time Core
    
- Donner Yellow Fall
    

Un **delay** ya cambia totalmente el sonido.

# 🧠 Trucos útiles

### Si el ampli suena muy sucio

```
Baja el gain
Sube el volumen master
Usa el SD-1 como boost
```

### Si el sonido es muy chillón

```
Baja el tono de la guitarra a 7–8
Cambia a pastilla centro
```

### Si el sonido es muy oscuro

```
Sube treble
Usa pastilla puente
```
